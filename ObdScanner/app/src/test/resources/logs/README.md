# Логове от истински коли

Сложете тук файл, изпратен от приложението („Информация“ → „Експорт на лога“), и добавете
най-отгоре ред с очаквания VIN:

```
# expect-vin: WVWZZZ1KZ8W123456
```

Тестът `VinTest.logsFromCarsReplay` пуска записа през същия код, който работи в колата
(`ReplayTransport` връща записаните отговори), и проверява, че се намира този VIN.

Файлове тук (всички от MUCAR BT200 в режим ELM327 по BLE, без VIN и модел на телефона):

- `vw-golf4-iso9141.txt` — Golf IV, свързване по ISO 9141-2 (версия 1.2);
- `vw-golf4-adapter-check.txt` — същата кола, „Провери адаптера“ (версия 1.4): K-line работи;
- `renault-scenic1-connect.txt` — Scénic I: модул се събужда на ISO 9141-2, но не говори OBD2.

Тестовете към тях са в `RealLogsTest`. Отговорът на Honda CR-V 2012 (19 02 FF) е вграден в теста.
